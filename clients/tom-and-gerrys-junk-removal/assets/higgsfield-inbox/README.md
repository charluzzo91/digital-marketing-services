# Higgsfield inbox

Drop raw generations here — from the web app or the CLI. Nothing in this folder ships.

Pipeline: `assets/higgsfield-inbox/` (raw) → select → vectorise/optimise → `public/brand/` (shipped).

Name files `YYYY-MM-DD_<asset>_<model>_v<n>.<ext>` so provenance stays traceable,
e.g. `2026-09-10_mascot-probe-a_gpt-image-2_v1.png`.

Log every generation in `creative/higgsfield-prompts/GENERATION-LOG.md`.
