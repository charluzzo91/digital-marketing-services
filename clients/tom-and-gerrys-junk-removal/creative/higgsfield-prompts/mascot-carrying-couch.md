# Mascot — Lifting a Couch

**Prerequisite:** approved `mascot-master-reference.png`. Pass it as a reference image.
**Route:** WEB · **Model:** GPT Image 2 · **2K / High** · **Aspect:** 3:2
**Use:** Services section (furniture removal)

## Prompt

> Using the supplied reference image as the exact character design, show the SAME character lifting
> one end of a large couch. Three-quarter view, knees bent in a proper lifting stance, back
> straight, both gloved hands gripping the couch frame, confident half-smile, slight strain in the
> posture but clearly in control.
>
> The couch is a simple flat-shape sofa in muted sage, drawn in the same flat vector style — no
> pattern, no detail beyond cushion divisions.
>
> Identical proportions, wardrobe, palette and outline weight to the reference. Flat vector
> editorial illustration, four flat colours plus outline, no gradients, no shading, no drop shadows,
> plain flat background, no scene. Full body visible, feet included, generous margin.
>
> Original character. Do NOT reference or evoke any existing animated franchise. No cat.

**Negative:** same list as `mascot-master.md`, plus `different character design, altered
proportions, changed wardrobe, realistic furniture, room interior, background scenery`

## Accept / reject
Accept only if proportions, wardrobe and outline weight match the reference exactly.
Any drift → targeted revision prompt, not a fresh generation.
